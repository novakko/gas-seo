Available APIs

Orchestrator API

Unified access to open-weight models hosted by Perplexity through one OpenAI-compatible endpoint.

Agent API

Get web-grounded answers with built-in citations in one call, or access third-party models from OpenAI, Anthropic, Google, and xAI with web search tools and presets.

Search API

Get raw, ranked web search results with advanced filtering and real-time data.

Embeddings API

Generate high-quality embeddings for semantic search and RAG pipelines.
